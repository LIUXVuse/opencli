# forex — 匯率查詢 + 換錢策略

即時查詢台灣銀行匯率，並自動計算越南換錢最佳方案（含金舖建議）。

## 資料來源

| 來源 | 地區 | 幣別 | 更新頻率 | 需要登入 |
|------|------|------|---------|---------|
| [台灣銀行](https://rate.bot.com.tw) | 🇹🇼 台灣 | 全部（含 VND、THB） | 每日 | 否 |
| [Vietcombank](https://vietcombank.com.vn) | 🇻🇳 越南 | USD/VND | 每日 | 否（⚠️ 每 5 分鐘限一次） |

> 越南金舖（tiệm vàng）匯率無公開 API，以 Vietcombank + 100 VND/USD 估算。

---

## 指令

### `forex rate` — 查匯率 + 越南策略

```bash
# 查旅遊常用幣別（VND、THB、USD、JPY、KRW、EUR、HKD）
opencli forex rate

# 指定金額（預設 10,000 台幣）
opencli forex rate --amount 30000

# 只查特定幣別
opencli forex rate VND
opencli forex rate THB --amount 5000

# 不顯示越南換錢策略
opencli forex rate --no-strategy

# JSON 輸出（方便串接其他工具）
opencli forex rate -f json
opencli forex rate VND -f json --amount 50000
```

### 輸出欄位說明

| 欄位 | 說明 |
|------|------|
| 現鈔賣出(TWD) | **出國前要看這個**：銀行賣外幣給你的價格（1 外幣 = X 台幣） |
| 能換到 | 用你指定的台幣金額能換到多少外幣 |
| 現鈔買入(TWD) | 回國把剩餘外幣賣回給銀行的價格 |

## 越南換錢策略說明

工具會自動比較三種方案：

| 方案 | 做法 | 優點 | 缺點 |
|------|------|------|------|
| **A** | 台灣直接換越南盾 | 簡單，不用多一個步驟 | 通常匯率最差 |
| **B** | 台灣換美金 → 越南 Vietcombank 換越南盾 | 即時真實匯率，差距可達 10%+ | 需要在越南找銀行 |
| **C** | 台灣換美金 → 越南金舖換越南盾 | 通常比銀行再好一點 | 需要找信任的金舖 |

### 推薦金舖地點

- **胡志明市**：Hai Bà Trưng 街（第 1 郡）、Bến Thành 市場周邊
- **河內**：Hàng Bạc 街（銀器街，也換外幣）
- **峴港、芽莊、美奈**：各市場附近的 tiệm vàng

> 換錢前建議比較 2-3 家金舖，100 USD 以上的金額差距更明顯。

## 實際計算範例（2026-04-02 資料）

帶 **30,000 台幣**去越南：

| 方案 | 能換到 |
|------|--------|
| A：台灣直換越南盾 | 21,739,130 VND |
| B：美金中轉（Vietcombank 26,112） | 24,290,233 VND |
| C：美金 → 金舖（估 26,212） | 24,383,256 VND |

**方案 B 比方案 A 多 2,551,102 VND（+11.7%）**
